## Arti status
Status Soon berarti menu belum tersedia penuh. Tidak ada dasar dokumentasi untuk menyatakan bahwa menu ini sudah menyediakan katalog GPT, aplikasi mini, agen, atau fungsi penjelajahan tertentu.

## Panduan untuk Sara
Jika pengguna bertanya cara memakai Jelajahi, jelaskan statusnya tanpa mengarang alur. Jangan menyebut daftar konten, tombol, hasil pencarian, atau kemampuan yang belum dikonfirmasi.

## Syarat sebelum dokumentasi diaktifkan
Setelah fitur benar-benar tersedia, dokumentasi harus diperbarui berdasarkan UI produksi: tujuan menu, cara menemukan item, cara membukanya, batasan, dan langkah saat konten tidak muncul. Perubahan status harus disertai pemeriksaan rute artikel agar pengguna tidak diarahkan ke halaman 404 secara tidak sengaja.
