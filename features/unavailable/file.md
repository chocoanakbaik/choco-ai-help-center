# Rute artikel lama: File

**Status produk:** Menu direncanakan / Soon.  
**Status rute bantuan:** Artikel lama sengaja dialihkan ke halaman 404.

Dokumen ini menjelaskan alasan rute lama dialihkan, bukan tutorial penggunaan fitur. Menu File yang terlihat pada aplikasi tidak boleh diperlakukan sebagai fungsi unggah aktif selama masih bertanda Soon.

Jangan menjanjikan pengguna dapat mengunggah, membaca, merangkum, mengonversi, atau menganalisis dokumen. Jangan mengarang jenis file yang didukung, batas ukuran, atau proses penyimpanan.

Rute HTML lama dipertahankan sebagai redirect ke 404 supaya artikel yang belum siap tidak tampil seolah-olah merupakan panduan yang benar. Jika fitur diluncurkan, perbarui katalog, artikel publik, dan rute ini secara bersamaan.
