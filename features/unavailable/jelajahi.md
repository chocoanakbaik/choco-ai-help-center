# Rute artikel lama: Jelajahi

**Status produk:** Menu direncanakan / Soon.  
**Status rute bantuan:** Artikel lama sengaja dialihkan ke halaman 404.

Dokumen ini bukan panduan penggunaan Jelajahi. Status Soon berarti fungsi belum tersedia penuh dan belum ada dasar untuk menjanjikan jenis konten atau kemampuan tertentu.

Sara harus menjelaskan status ini secara jelas dan tidak mengarang daftar fitur, tombol, alur pencarian, atau hasil penjelajahan. Rute HTML lama mengarah ke 404 agar pengguna tidak menerima tutorial yang belum sahih.

Setelah implementasi tersedia dan diuji, ganti status katalog, tulis artikel berdasarkan UI aktual, lalu periksa semua tautan agar tidak lagi menuju rute lama.
