# Pengelolaan profil pengguna

**Status katalog:** Tidak disediakan sebagai menu mandiri pada UI saat ini.

## Yang terlihat di aplikasi
Antarmuka saat ini tidak menyediakan menu Profil atau form untuk mengedit data pengguna. Area di bagian bawah sidebar menampilkan identitas produk Choco AI dan pengembang. Setelah login Google, kode aplikasi dapat membuat atau memperbarui record profil secara internal; record tersebut bukan halaman pengelolaan profil untuk pengguna.

## Panduan untuk Sara
Jika pengguna bertanya cara membuka atau mengedit profil, jelaskan bahwa kontrol profil mandiri belum tersedia pada UI saat ini. Jangan menyuruh pengguna mencari menu Profil, menjanjikan form edit, atau mengklaim Sara bisa membaca maupun mengubah data akun.

Label akun di bagian atas dapat memakai nama yang dikembalikan Google atau alamat email sebagai cadangan. Tidak ada jaminan perubahan informasi Google langsung memperbarui semua record atau tampilan sebelum data autentikasi disegarkan.

**Artikel terkait:** `mengelola-profil`, `mengubah-data-profil`, `data-akun`.
