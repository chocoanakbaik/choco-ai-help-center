# Obrolan baru

**Status:** Tercatat sebagai kontrol aplikasi.

## Fungsi
Obrolan baru memulai sesi percakapan dengan konteks terpisah. Ini berguna saat pengguna berganti topik dan tidak ingin jawaban baru bergantung pada pembahasan sebelumnya.

## Cara menggunakan
1. Pilih tombol **Obrolan baru**.
2. Pastikan tampilan memulai sesi baru.
3. Kirim pesan pertama untuk topik baru.

## Hal penting
Memulai obrolan baru tidak otomatis menghapus chat lama. Jangan menjanjikan chat lama bisa dibuka kembali jika UI belum menyediakan daftar riwayat.
