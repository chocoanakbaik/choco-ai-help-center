# Template pertanyaan

**Status:** Tersedia pada halaman awal sesuai dokumentasi saat ini.

## Fungsi
Template adalah contoh pesan siap pakai agar pengguna tidak perlu memulai dari halaman kosong. Template bukan jawaban otomatis dan tidak menjamin hasil tertentu.

## Template yang tercatat
- **Cari ide baru:** meminta bantuan menghasilkan ide.
- **Bantu coding:** meminta bantuan memahami atau memperbaiki kode.
- **Belajar sesuatu:** meminta penjelasan topik.
- **Analisis masalah:** meminta bantuan mengurai masalah secara logis.

## Cara menggunakan
1. Buka halaman awal Choco AI.
2. Pilih template yang sesuai.
3. Tinjau teks pertanyaan yang digunakan.
4. Sesuaikan konteks bila perlu, lalu kirim.
